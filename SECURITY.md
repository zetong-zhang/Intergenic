# Security Policy

## Reporting a vulnerability

Do not open a public issue for a potential security vulnerability. Email
`zhangzetong@tju.edu.cn` with:

- affected version or commit;
- reproduction steps;
- potential impact;
- any suggested mitigation.

Please allow reasonable time for confirmation and remediation before public
disclosure. The maintainer will acknowledge reports when possible and coordinate
a disclosure timeline for confirmed issues.

## Supported versions

Security fixes are applied to the latest release and the `main` branch.
