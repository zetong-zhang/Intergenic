# Support

## Questions and usage help

Open a GitHub issue using the feature-request or question template. Include:

- Intergenic version or commit;
- operating system and compiler;
- exact command and sanitized input format;
- whether annotations are external or embedded;
- complete error output.

## Bug reports

Use the bug-report template and provide a minimal reproducible example. Security
issues should **not** be posted publicly; follow [SECURITY.md](SECURITY.md).

## Scope

Maintainers support the latest released version on its documented platforms.
Questions about third-party tools such as Clovers, Prodigal, or HMMER should be
directed to those projects unless the problem is caused by Intergenic output.
